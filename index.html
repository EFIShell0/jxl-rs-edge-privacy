01

Local processing

JXL-RS Edge processes supported images on the device using its packaged decoder. Files selected in the viewer, decoded image samples and embedded metadata are used locally to display images. The extension has no developer-operated image upload, analytics, advertising, account system or telemetry.

Local files are opened through the file picker or an explicit drop into the viewer. The viewer checks file signatures and resource limits. The local PDF reader uses packaged PDF.js and the JPEG XL decoder. PDF documents, passwords, form values, annotations, search terms, signature integrity checks and limited preflight metadata are processed on the device. Edited copies are downloaded only when requested. Certificate trust and full standards conformance are not determined. Document scripting, external links, automatic network actions and embedded-file launch are disabled; explicitly saving or printing uses the browser or operating system. Experimental JPEG XL image viewing is limited to supported image profiles.

02

Website requests

The extension can inspect image URLs and page elements on supported websites to display JPEG XL and provide on-device diagnostics. It may retrieve images from websites you visit or from supported direct web image navigation.

Requests go to the image host, rather than a developer-operated service. Websites may receive ordinary connection information such as your IP address. The page image fetch path uses same-origin credentials and may follow redirects; the direct web viewer fetch path omits credentials and rejects redirects. Both request no referrer. Websites have their own privacy practices.

03

Storage & diagnostics

Automatic HDR/SDR presentation and optional web-link routing preferences are stored locally in the browser until changed, cleared or the extension is removed. Legacy manual display values are not used. Image decoding uses transient memory.

Display diagnostics
Optional display details and headroom are read locally after you request display access. Results are not sent to the developer.
Save original
Writes a user-requested copy through the browser. The source file is not changed.
Developer data use
The extension does not send your local files to the developer. The developer does not sell, transfer or use image data for other purposes.
04

Your controls

You can manage or revoke site access, disable the extension or uninstall it using your browser settings. You may also decline optional display access. Edge, your operating system, network provider and websites have independent privacy practices.
